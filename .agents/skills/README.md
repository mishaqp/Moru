# Скилы Moru

Общий источник — `.agents/skills/<имя>/SKILL.md`. В `.claude/skills` находится
симлинк `../.agents/skills`, поэтому Codex и Claude Code читают те же файлы.
Условия выбора перечислены в [AGENTS.md → Skills](../../AGENTS.md#skills).
Инструкции пользователя имеют приоритет над скилами.

## Формат и загрузка

Сверено 4 октября 2026 года с [документацией Codex](https://developers.openai.com/codex/skills/),
[спецификацией Agent Skills](https://agentskills.io/specification) и
[документацией Claude Code](https://code.claude.com/docs/en/skills).

- Codex ищет `.agents/skills` от текущего каталога до корня Git-репозитория.
  Запускайте его в корне Moru или внутри него. Явный вызов — `$moru-perf`
  (аналогично для остальных), список — `/skills`.
- Claude Code ищет проектные скилы в `.claude/skills`; явный вызов —
  `/moru-perf`. Симлинк подключает общий каталог без копий.
- `SKILL.md` начинается с YAML frontmatter между `---`: обязательны `name`
  и `description`. Имя совпадает с каталогом: 1–64 символа, строчные буквы,
  цифры и одиночные дефисы. Описание — 1–1024 символа с точным условием
  срабатывания; стиль Moru задан в [памятке для Codex](../../docs/prompting-codex.md#длинные-задачи).
- Вначале загружаются имя и описание, тело — при выборе скила. Подробности
  лежат в связанных `references.md`, команды и примеры проверяются по коду.
  Необязательные `scripts/`, `references/`, `assets/` и `agents/openai.yaml`
  нужны только при появлении соответствующих ресурсов или метаданных.

Формат и обнаружение набора проверяются штатным загрузчиком Codex CLI,
в том числе при запуске внутри подкаталога Moru. Для этой правки приложение
и Flutter-тесты не нужны.

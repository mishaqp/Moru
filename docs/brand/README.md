# Знак Moru

Знак `m_` — имя, набранное как команда в терминале: строчная «m» и курсор.
Moru готов действовать: чат, агенты, Linux-окружение и браузер в телефоне.

## Файлы

- `final-symbol.svg`, `final-symbol-color.svg` — знак (чёрный и цветной).
- `final-symbol-small.svg` — для 16–24 px: курсор толще.
- `final-wordmark.svg`, `final-wordmark-color.svg` — надпись `moru_`.
- `app-tile.svg` — иконка на тёмной плитке (источник `assets/app_icon.png`).
- Иконки лаунчера: `assets/icon/` → `dart run flutter_launcher_icons`
  (фон, передний план и монохромный слой для тематических иконок Android 13+).

## Цвета

| Роль | HEX |
|---|---|
| Чернила (плитка, знак на светлом) | `#14161B` |
| Бумага (знак на тёмном) | `#F3EFE6` |
| Курсор (акцент) | `#FFB020` |

Одноцветная версия: весь знак одним цветом. Курсор не растягивать и не
отделять от «m»; свободное поле вокруг знака — не меньше ширины курсора.

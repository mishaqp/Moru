# «Компьютер» и встроенный браузер Android

Источник требований — пользовательское ТЗ частей А–Г. Единая полоска над композером и лист на 85% высоты показывают все tool-шаги одного ответа; план остаётся рядом. Карточки инструментов открывают тот же лист. Сохраняются фоновые команды, подтверждения, навигация, библиотека, юзерскрипты, консоль и Ask AI.

Данные адаптируются из текущих ToolUIPart/ToolCallPart без новой БД, статусы и вывод команд — ToolRunRegistry, сведения браузера — BrowserAgentSession. Выбор хранится по стабильному id: следование за последним работающим шагом, ручное закрепление работающего шага, возврат к последнему. После окончания ответа полоска кратко показывает результат и сворачивается; активные фоновые команды сохраняют доступ.

Миниатюры: браузер и изображение — уменьшенное превью; команда — хвост вывода; файл — имя и первые строки; остальные — lucide-значок. Скриншоты браузера кэшируются на чат, максимум 24 превью шириной 480 px; UI не вызывает native capture. Последний доступный скриншот того же чата подставляется при отсутствии нового. Реальный screenshot tool сохраняет свою точность.

Лист использует общий CustomBottomSheet, прокрутку, адаптивную шапку и нижний статус. Действие открывает терминал, живой браузер, файл или копирует очищенный результат. Отображение и копирование используют существующие фильтры секретов/auth URL; исполняемые данные не меняются.

Минимизация сохраняет исходный WebViewController. Плавающий браузер включается настройкой, по умолчанию доступ через полоску/общий браузер. Material окружает overlay-карточку; меню имеет одинаковые строки, переключатель справа и разделители. История посещений и действия ИИ различаются иконками. Нижняя навигация имеет ясные disabled-состояния и цели 48dp.

Тема приложения и «Стекло», flutter_animate/animations, клавиатура, landscape и textScaler 1.3. Все новые строки в пяти ARB, generated output включён. Тесты при разработке только shared/home/затронутые; полный чеклист AGENTS.md один раз перед push. PNG до/после в docs/design/browser. Из OpenMinis можно использовать только идеи, GPL/Kotlin код не копируется.

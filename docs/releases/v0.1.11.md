## Обновлённый встроенный браузер

Полная переработка интерфейса и логики общего браузера ИИ: внешний вид, взаимодействие с ассистентом, настройки действий и надёжность кода.

- **Интерфейс**: одна компактная верхняя панель вместо дублирующихся адресных строк (домен + короткий заголовок страницы, редактор полного URL по тапу с проверкой и понятной ошибкой при неверном адресе). Навигация и обращение к ИИ объединены в одну нижнюю панель с семью различимыми состояниями («запускается», «работает», «ожидает подтверждения», «останавливается», «завершено», «остановлено», «ошибка») — состояние «останавливается» больше никогда не выглядит как уже завершённое. Отдельный экран ошибки для сбоя основной страницы (причина + «Повторить»); ошибка отдельного ресурса страницы больше не подменяет всю страницу.
- **Ответ ИИ в браузере**: раньше при обращении к ИИ через плавающую строку браузера пользователь не видел сам ответ — только факт успеха/ошибки. Теперь настоящий текст ответа ассистента показывается прямо в браузере: компактная карточка, раскрытие в полный текст, копирование, явное закрытие. Ответ остаётся на экране после завершения задачи и не пропадает от последующей активности ИИ на странице.
- **Подтверждение действий**: кнопка «Всегда разрешать» убрана из карточки подтверждения браузерного действия — теперь только «Отклонить» и «Разрешить один раз»; включение полного доверия происходит исключительно в реальных настройках доверия инструментам (по ссылке из карточки), без дублирующего переключателя. Код `eval_js` теперь показывается полностью в прокручиваемой области, а не обрезается до 6 строк.
- **Настройки → Браузер**: список действий сгруппирован в четыре сворачиваемых раздела (Навигация / Чтение страницы / Взаимодействие / Дополнительно) со счётчиком включённых действий по каждой группе; формулировки переписаны понятным языком.
- **Исправлены реальные ошибки логики**:
  - отмена запроса к ИИ, поступившая до фактического старта генерации, раньше терялась и генерация всё равно продолжалась — теперь отмена всегда учитывается;
  - карточка подтверждения браузерного действия могла показать запрос из другой (уже неактуальной) беседы вместо своей — теперь подтверждение строго привязано к владеющей беседе;
  - журнал активности браузера переведён с модели «последнее действие» на модель по уникальным ID: результат каждого вызова теперь применяется к тому самому вызову, а не к «текущему последнему», что раньше могло приводить к присвоению результата не тому действию при параллельных или быстро следующих друг за другом вызовах;
  - закрытие браузера (вручную или по действию `browser_use: close`) теперь корректно отменяет собственный незавершённый запрос к ИИ этой страницы, чтобы он не продолжал работать незаметно после закрытия окна.

## Известные ограничения

- Реализация покрыта широким набором модульных и виджет-тестов, включая реальные отрендеренные скриншоты интерфейса (360dp, масштаб текста 200%, открытая клавиатура, тёмная и светлая темы), лично просмотренные перед релизом. Настоящее использование нового интерфейса браузера на физическом Android-устройстве этим релизом не проверялось — рекомендуется ручной smoke-тест после установки.

## Проверки и APK

Перед публикацией workflow выполняет полный Dart analyze, Flutter tests, Android JVM tests, проверку arm64 ABI, release-подписи и package metadata.

Один **arm64-v8a release APK**, версия **0.1.11**, versionCode **12**, пакет `com.mishaqp.moru`. Используется постоянный сертификат Moru; релиз предназначен для установки поверх предыдущего подписанного Moru без удаления данных.

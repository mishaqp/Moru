# Moru v0.1.27 — без подлагиваний во время длинного ответа

## Изменения

- **Сохранение ответа больше не тормозит интерфейс.** Пока модель отвечает, черновик ответа сохраняется в базу до четырёх раз в секунду. Раньше при каждом сохранении все результаты инструментов (чтение файлов, вывод команд, правки) заново разбирались из JSON и собирались обратно, причём в потоке интерфейса. Чем больше шагов было в ответе, тем дольше это длилось, поэтому длинный агентный ответ заметно подлагивал.
  - Теперь каждый результат разбирается один раз, а собранный JSON используется повторно, пока содержимое не изменится. Заново собирается только шаг, который изменился.
  - На ответе из 80 шагов (~0,9 МБ результатов) работа в потоке интерфейса на одно сохранение сократилась с 4–9 мс до ~0,13 мс на тестовом сервере. На телефоне разница больше.
  - Совпадение проверяется по содержимому, а не по «тому же объекту». Если результат изменили на месте, в базу всё равно попадёт новое значение (это проверяет отдельный тест).

## Замеры

- `test/perf/streaming_checkpoint_bench.dart`: новый замер «checkpoint cost of a long agent reply».
- `test/perf/agent_stream_bench.dart`: новый замер обновления агентного ответа с 10, 40 и 80 шагами. Время кадра почти не растёт с числом шагов, потому что шаги уже кэшируются. Замер оставлен для следующих оптимизаций.

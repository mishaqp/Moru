# Moru v0.1.47

Эта версия собирается из постоянного PR: каждый раздел сначала выходит пререлизом для проверки на телефоне, а в стабильный релиз попадает после вашей проверки.

## Сборка: пререлизы вместо ожидания

- **Пререлиз на каждое изменение.** Каждое изменение в PR автоматически собирает release-APK, подписанный постоянным ключом Moru, и публикует его как пререлиз `v0.1.47-pre.N`.
  - Ставится поверх Moru без удаления, чаты и настройки сохраняются.
  - Размер как у обычного релиза, около 38 МБ.
  - Предыдущий пререлиз удаляется, чтобы список не засорялся.
- **Релиз без пересборки.** После мёржа в master последний проверенный пререлиз становится стабильным релизом `v0.1.47`: тот же APK, без пересборки и повторного ожидания. Перед этим CI сверяет, что код в master в точности совпадает с кодом пререлиза.
- **Быстрее.** Ссылка на пререлиз появляется примерно через 15 минут после изменения. Раньше релиз выходил примерно через час после мёржа.

## Мелкие исправления

- **Озвучка больше не засоряет память.** Раньше каждый кусок сетевой озвучки сохранялся во временный файл и оставался там навсегда: при частом использовании это сотни мегабайт.
  - Теперь хранится только один файл, который играет сейчас. Он удаляется, когда озвучка закончилась или её остановили.
  - Остатки прошлых версий удаляются при запуске.
- **Moru вместо Kelivo.**
  - В списке недавних приложений Android теперь отображается «Moru».
  - На экране «О приложении» тоже «Moru».
  - Сохранённый файл озвучки называется `moru_tts_…`.
- **Кнопка «Озвучить» не перерисовывается лишний раз.** Во время озвучки каждое сообщение в чате обновляло свою кнопку десятки раз в секунду. Теперь кнопка меняется только когда озвучка начинается или заканчивается.

## Проверка

- Новый тест: при сетевой озвучке во временной папке не больше одного аудиофайла, после остановки ни одного. Остатки прошлых запусков удаляются, чужие файлы не трогаются.
- Тесты скриптов упаковки: пререлиз получает свой тег и имя файла, а при повышении до релиза сохраняется тот же APK с проверкой контрольной суммы, версии и метаданных.
- CI: анализ, Flutter-тесты, локализация, Android JVM-тесты, сборка одного `arm64-v8a` APK, подписанного постоянным сертификатом Moru, и проверка release-APK.

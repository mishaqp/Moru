## Вход Codex на Android

В журнале телефона выдача кода завершалась успешно, но последующие запросы Moru обрывались с `device-poll/dns` или `token-exchange/dns`, пока пользователь проходил вход в браузере. Одни короткие DNS-повторы не помогли.

- Интерактивный вход Codex теперь ждёт возврата Moru на передний план, затем — сигнала Android о разблокированной сети приложения. Используется текущая сеть приложения, включая VPN; маршрутизация, DNS, прокси и проверка сертификатов не изменяются.
- Ожидание не расходует 15-секундный таймаут HTTP-запроса. Весь вход ограничен 15 минутами; отмена и завершение удаляют сетевые наблюдатели и таймеры.
- DNS-повторы также проходят проверку готовности. HTTP-ответы, TLS-ошибки, таймауты и неизвестные транспортные ошибки не приводят к повторной отправке одноразового кода.
- Страница localhost содержит кнопку возврата в Moru. Возврат использует собственную схему приложения; OAuth-код не передаётся в deep link. Зарегистрированный OpenAI redirect, PKCE, state, проверка токенов и чтение тарифа Pro сохраняются.
- При входе по коду после подтверждения в браузере вернитесь в Moru: приложение продолжит ту же попытку, а не начнёт новую.

## Собственный канал обновлений

Moru проверяет только стабильные GitHub-релизы `mishaqp/Moru`. Обновления Kelivo и китайский баннер из его сервера больше не используются. Принимается только полностью опубликованный APK Moru нужной версии и архитектуры arm64-v8a из этого же репозитория.

## Проверки и APK

Добавлены регрессии возврата из браузера, паузы приложения, отмены сетевого ожидания, неизменности OAuth-запросов при DNS-повторе, таймаутов и фильтрации обновлений. Перед публикацией workflow выполняет полный анализ, Flutter-тесты, Android JVM-тесты, проверку ABI и постоянной подписи.

Один **arm64-v8a release APK**, версия **0.1.4**, versionCode **5**, пакет `com.mishaqp.moru`. Ключ подписи и данные приложения не меняются. Устанавливайте поверх предыдущего подписанного Moru, не удаляя приложение.

Успешный вход в реальный аккаунт и работу сети именно на вашем телефоне CI проверить не может; это проверяется после установки. Эта версия исправляет обнаруженные проблемы обработки фонового состояния и канала обновлений, а не гарантирует доступность внешнего сервиса при любой конфигурации сети.

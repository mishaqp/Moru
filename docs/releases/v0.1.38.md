# Moru v0.1.38 — проход по разделу «Внешний вид и поведение»

Релиз без новых функций: оптимизация, удаление ненужного кода и разбор экранов раздела. Что делать, выбрали перед началом работы.

## Проход по разделу «Внешний вид и поведение»

### Тема больше не перестраивает всё приложение

- **Что было.** Корень приложения следил за всеми настройками сразу. Любое изменение — выбор модели, переключатель инструмента, бюджет рассуждений, настройка провайдера, ширина боковой панели на планшете при перетаскивании — заново собирало светлую и тёмную темы.
- **Почему это было дорого.** У цветового расширения темы не было сравнения, поэтому каждая пересобранная тема считалась новой. Приложение запускало 200-миллисекундную анимацию перехода к «новой» теме, и в каждом её кадре перестраивался открытый экран.
- **Что стало.**
  - Корень следит только за настройками темы: палитра, своя тема, динамические цвета, чистый фон, слои, шрифт, режим, язык.
  - Цвета темы сравниваются по значению.
  - Прокси и фоновый режим отслеживают свои настройки отдельно.
  - Проверка обновлений запускается один раз после загрузки настроек.
- **Замер.** 40 изменений посторонней настройки:
  - было: 160 кадров, 80 перестроек экрана, **12,8 мс** на изменение;
  - стало: 40 кадров, 0 перестроек, **0,5 мс**.
- **Клавиатура.** Корень больше не пересобирается при открытии клавиатуры. Раньше код для «плавающего iPad» заставлял его пересобираться в каждом кадре анимации клавиатуры и каждый раз заново настраивать фоновый сервис.

### Экраны раздела

- **Разбиение файлов.** `display_settings_page.dart` (2342 строки, пять страниц в одном файле) разбит по страницам: главная, отображение в чате, рендеринг, поведение, вибрация, общие строки. От экрана стиля сообщений отделены строки настроек и превью (1322 → 570 строк в основном файле).
- **Подписки.** Каждая страница следит только за настройками, которые показывает. Мс на одно постороннее изменение настроек (медиана):

| Экран | Было | Стало |
|---|---|---|
| Внешний вид и поведение | 17,1 | 1,5 |
| Отображение в чате | 16,8 | 0,6 |
| Рендеринг | 10,3 | 0,5 |
| Поведение | 26,7 | 0,9 |
| Стиль сообщений | 9,8 | 5,3 |

  Стиль сообщений ускорился меньше, потому что его превью рисует настоящие пузыри чата, а они сами следят за настройками. Это часть чата, а не этого раздела.

### Удалённый код

- Проверки «Android или iOS» и «не Web» в настройках раздела: на Android они всегда давали один ответ.
- Десктопный вариант выбора шрифта в диалоге и десктопный диалог стиля сообщений вместе с его тестом.
- Подстройка экрана под «плавающий iPad» в корне приложения.
- Запасной набор шрифтов для Windows и два теста, проверявшие только его.
- Закомментированный отладочный вывод цветов темы.

Итого по удалению: 7 файлов, −204 / +42 строки. Поведение на Android не менялось.

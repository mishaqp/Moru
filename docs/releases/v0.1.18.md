# Moru v0.1.18 — только Android, без кода ПК и iOS

## Изменения

- Из репозитория удалены проекты iOS, macOS, Windows, Linux и Web, а также оболочка ПК-версии: окно, трей, горячие клавиши, настольные главная страница и настройки. Приложение при запуске сразу открывает мобильный главный экран и больше не выполняет подготовку окна ПК.
- Убраны неиспользуемые на Android пакеты (`bitsdojo_window`, `screen_retriever`, `tray_manager`, `hotkey_manager`, `reorderable_grid_view`, `system_fonts`) и иконки для Windows и macOS, которые попадали в APK.
- Все функции Android сохранены: PRoot/Linux-окружение, терминал, рабочие файлы, MCP, браузер, резервные копии, переписки и настройки.
- Исправлены два нестабильных теста (резервное копирование и провайдер файлов рабочего пространства), из-за которых сборки иногда падали без реальной ошибки в приложении.
- GitHub-сборки переведены на актуальные версии GitHub Actions (Node 24), лишний повторный прогон тестов убран, устаревшие прогоны отменяются при новом push.
- Добавлены проверки, которые не дают обновлению из Kelivo или правкам другой ИИ вернуть удалённые платформы, пакеты ПК и файлы `lib/desktop`.

## Проверка

- CI: анализ, Flutter-тесты, локализация, Android JVM-тесты, политика «только Android» и сборка одного `arm64-v8a` APK.
- Релизная сборка подписана постоянным сертификатом Moru; обновление поверх v0.1.17 сохраняет данные.

Версия **0.1.18** (`versionCode 19`), пакет `com.mishaqp.moru`.

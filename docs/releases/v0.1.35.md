# Moru v0.1.35 — мини-приложения из чата, moru.ai, напоминания

## Изменения

- **Данные мини-приложений из чата.** Новый локальный инструмент «Мини-приложения» (`mini_apps`) читает и меняет данные ваших приложений без их открытия. Например, можно написать «выпил стакан воды», и трекер воды получит запись.
  - Включается в настройках ассистента на вкладке локальных инструментов.
  - Модель сначала получает список приложений: что каждое делает, в каком формате хранит данные и какие у него ключи. Потом она читает нужный ключ и записывает новое значение в том же формате.
  - Открытое приложение сразу перерисовывается: страница получает событие `moru:storage`.
  - Приложение может описать свой формат данных в поле `data` файла `moru-app.json`. Агент заполняет его при публикации.
- **`moru.ai.ask`.** Приложение может задать вопрос модели по умолчанию и получить текст ответа. Например, «придумай рецепт из того, что в списке покупок». Одновременно выполняется только один запрос, лишний вызов получает ошибку «подождите».
- **`moru.notify`.** Приложение показывает уведомление. Нажатие на него открывает это приложение. При первом вызове Moru спросит разрешение на уведомления.
- **Напоминания `moru.reminders`.** Приложение ставит напоминание на время (`HH:mm`), по дням недели или каждый день. Оно приходит, даже когда Moru закрыт, и переживает перезагрузку телефона. Нажатие открывает приложение.
  - До 20 напоминаний на приложение.
  - При удалении приложения удаляются и его напоминания.
  - Если телефон разрешает точные будильники, время точное, иначе Android может сдвинуть напоминание на несколько минут.
- Описание инструмента `publish_mini_app` рассказывает агенту про новые возможности, поэтому новые приложения сразу их используют.

## Проход по разделу «Провайдеры»

- **Меньше перестроек.** Экран провайдера, список провайдеров, аватары, значок баланса, ключи и свои запросы теперь подписаны только на свой провайдер, а не на все настройки сразу. Раньше любое изменение настроек (баланс другого провайдера, переключение темы, сохранение ключа) заново строило весь экран.
  - Замер на вкладке «Модели» с 300 моделями, когда меняется другой провайдер: **44–46 мс → ~1 мс** на кадр (медиана).
  - Значок баланса больше не перезапрашивает баланс при чужих изменениях.
- **Порядок моделей.** Перетаскивание сразу сохраняет новый порядок без лишнего кадра со старым.
- **Исправление.** В режиме выбора модели можно было потащить: список дёргался и возвращался обратно. Теперь в режиме выбора и во время поиска перетаскивание выключено.
- **Поиск моделей.** Если у провайдера 10 моделей и больше, над списком появляется поиск по id и своему названию. «Выбрать все» выбирает только найденные, поэтому удобно удалить или проверить группу моделей.
- **Код.** Файл экрана провайдера разделён: карточка модели, окно проверки соединения и мелкие виджеты вынесены в отдельные файлы (4834 → 4088 строк в основном файле). Поле поиска общее для списка провайдеров и моделей. Десктопных веток и мёртвого кода в разделе не найдено.

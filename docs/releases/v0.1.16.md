# Moru v0.1.16 — удаление встроенной LiteRT-LM

## Изменения

- Убрана встроенная поддержка локальных моделей LiteRT-LM: Android SDK/плагин, экран управления моделями, загрузка и импорт файлов моделей, локальная генерация ответов и связанные строки интерфейса.
- При обновлении устаревшая конфигурация провайдера и скачанные/импортированные копии моделей из `litert_models` удаляются автоматически. Оригинальные файлы вне приложения (например, в Downloads) не трогаются.
- Чаты, ранее привязанные к локальной модели, переключаются на модель ассистента или общую модель по умолчанию.
- Восстановление из резервной копии больше не возвращает устаревший локальный провайдер.
- История переписок, PRoot/Linux-окружение, терминал/PTY, STDIO MCP и модели распознавания речи (ASR) не затронуты.

## Проверка

- Релизный workflow запускает анализ и тесты Flutter, Android JVM-тесты, собирает APK только для `arm64-v8a` и проверяет подпись постоянным сертификатом Moru.
- Локально: `dart analyze --fatal-infos`, полный `flutter test`, Android-only policy tests — без падений.

Версия **0.1.16** (`versionCode 17`), пакет `com.mishaqp.moru`.

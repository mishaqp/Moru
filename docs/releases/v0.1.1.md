## Исправления Codex / ChatGPT

- Вход по коду принимает оба варианта ответа сервера: `user_code` и `usercode`.
- Успешный вход и обновление сессии больше не отклоняются из-за отсутствия `expires_in`, когда срок действия указан в `exp` access-токена.
- Тариф, включая Pro, берётся из данных аккаунта. API-ключ не подставляется и тариф не подменяется.
- Добавлены шесть проверок авторизации, включая обновление токена и сохранение сессии, и проверки безопасности релизной упаковки.

## Вход с подпиской Pro

Для входа по коду включите device code authorization для Codex в настройках безопасности ChatGPT, затем начните вход в Moru заново и подтвердите новый код в браузере. Используйте тот аккаунт ChatGPT, на котором оформлена Pro.

Официальная инструкция: https://developers.openai.com/codex/auth

Проверки используют тестовый HTTP-транспорт. Фактический вход в конкретный аккаунт подтверждается на устройстве; предоставленный диагностический лог содержал только ошибки SiliconFlow, не запросы Codex.

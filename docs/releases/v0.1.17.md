# Moru v0.1.17 — Kelivo 1.3.0 и обновление входа

## Изменения

- Интегрированы изменения Kelivo 1.3.0 для Android: подготовка задач по расписанию, настройки поисковых сервисов Kagi и Kimi, привязка рабочего пространства по умолчанию и инструмент управления телефоном. Управление телефоном включается вручную в настройках ассистента и требует отдельного включения службы специальных возможностей Android.
- Обновлены идентификаторы клиентов для входа через аккаунты ChatGPT/Codex (`0.156.1`) и Claude (`2.1.280`). Добавлена обработка Claude Opus 5.5: обязательное адаптивное мышление с минимальным уровнем при выборе «выкл.» и поддержка встроенных инструментов.
- Добавлены русские переводы новых строк Kelivo 1.3.0. Сохранены браузер и «Спросить ИИ», PRoot, терминал, рабочие файлы, MCP, переписки и настройки Moru. Встроенные локальные LLM-модели не возвращены.

## Проверка

- Слияния Kelivo 1.3.0 и обновления входа прошли CI: анализ, Flutter-тесты, локализация, Android JVM-тесты и сборка одного `arm64-v8a` APK.
- Релизный workflow дополнительно проверяет полный набор тестов, идентификатор пакета, версию, ABI и подпись постоянным сертификатом Moru. Публикация в GitHub Releases выполняется отдельным ручным запуском после успешной сборки.
- При переходе с установленного debug APK может потребоваться переустановка из-за другой подписи; сохраните резервную копию приложения перед заменой сборки.

Версия **0.1.17** (`versionCode 18`), пакет `com.mishaqp.moru`.

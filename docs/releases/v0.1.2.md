## Codex: возврат из браузера на Android

- Добавлено завершение входа через полный callback URL. Если после входа браузер показывает ошибку `localhost:1455`, скопируйте весь адрес из строки браузера, вернитесь в ожидающее окно Moru и вставьте его в поле авторизации. Нужен URL именно этой попытки: старые ссылки не принимаются.
- Сохранены PKCE, проверка state и зарегистрированный адрес возврата. Посторонние адреса, повторные параметры, ссылки из другой сессии и повторное использование отклоняются.
- Подтверждённый локальный callback больше не ждёт второго Android-перехода. Занятый порт не блокирует резервный вход через браузер.
- Для OAuth добавлены безопасные диагностические коды этапа и сетевой причины (DNS/TLS/таймаут/соединение). При включённом журнале пишутся только этап, статус и категория: без кодов входа, URL с параметрами, паролей, PKCE и токенов.
- Поле авторизации не использует автокоррекцию и подсказки клавиатуры; введённое значение очищается после завершения попытки.

## Подписка и проверка

Вход остаётся через аккаунт ChatGPT; Pro не заменяется API-ключом и не назначается искусственно. Сетевая ошибка на конкретном телефоне пока не воспроизведена: этот релиз исправляет подтверждённые ошибки возврата и добавляет диагностику вместо предположений. Тесты с синтетическими учётными данными не равны проверке входа в реальный аккаунт.

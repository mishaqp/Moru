# Moru v0.1.46 — чистка кода под Android

Большая уборка мёртвого кода по всему приложению. Всё, что работало только на iOS, macOS, Windows, Linux или в браузере, удалено: на Android этот код никогда не выполнялся.

**Внешне приложение не меняется.** Настройки, чаты, рабочие пространства, терминал, STDIO MCP и планшетная раскладка остаются как были.

## Итог в цифрах

- **Код приложения:** удалено около 11 900 строк Dart. Не считаются строки перевода и сгенерированная локализация.
- **Файлы:** удалено 32 файла кода и тестов.
- **Строки перевода:** удалено 428 неиспользуемых строк (на каждом из пяти языков).
- **Пакеты:** удалены три пакета, которые на Android не использовались: `cupertino_http`, `webview_windows`, `haptic_feedback`. APK становится чуть легче.

## Что удалено

### Десктопные и iOS-движки

- **Десктопный движок команд** (запуск процессов на хосте macOS/Linux/Windows). На Android команды выполняются в PRoot, он не тронут.
- **iOS-среда рабочего пространства** (iSH/Alpine) и её установщик.
- **Запланированные задачи:**
  - удалены десктопный планировщик и iOS-«подготовка» результатов заранее (около 1 000 строк);
  - на Android задачи работают, как раньше, через системный планировщик;
  - в редакторе задачи остались только нужные переключатели: уведомление о результате и текст результата в уведомлении.
- **iOS-инструменты устройства:** погода (WeatherKit), здоровье (HealthKit), напоминания (EventKit). На Android их не было в списке инструментов.
- **iOS-перевод выделенного текста в коде.** Меню выделения теперь стандартное.

### Десктопные ветки интерфейса

- **Главный экран:**
  - правая боковая панель, перетаскивание ширины панелей;
  - панель рабочих пространств;
  - обработчики удалённых горячих клавиш.
- **Боковое меню:** десктопные вкладки «Ассистенты / Темы», подгрузка чатов при наведении мыши, режимы только тем / только ассистентов.
- **Десктопные диалоги** деталей инструмента, системного промпта, просмотра изображений, выбора ассистента и группы QQ. На Android открываются те же нижние листы, что и раньше.
- **Таблицы в Markdown:** широкая десктопная раскладка. На телефоне таблица и раньше показывалась компактно.
- **Настройки, которые Android никогда не читал:** трей, сворачивание в трей, заголовок окна Linux, позиция панели тем, ширина и состояние боковых панелей.

### Ветки кода

Около 300 проверок вида «если iOS / macOS / Windows / Linux / Web» по всему коду заменены их значением для Android, а ставшие недостижимыми ветки удалены.

## Тесты

- Удалены тесты, которые проверяли только удалённое поведение: десктопные диалоги, iOS-подготовку задач, HealthKit и WeatherKit, десктопные вкладки меню и т. п.
- Тесты, которые перебирали платформы, теперь проверяют Android.
- Тесты редактора MCP-сервера проверяют аргументы и переменные окружения на Android, с привязкой к рабочему пространству.
- **Сквозной тест отмены генерации** раньше запускал команду через удалённый десктопный движок. Теперь он запускает настоящую команду через тестовый движок с тем же контрактом, так что проверка не потерялась.

## Проверка

- Анализ без замечаний, полный набор Flutter-тестов.
- Проверки политики Android-only, arm64-APK и правил R8.
- CI:
  - анализ, Flutter-тесты, локализация;
  - Android JVM-тесты;
  - сборка одного `arm64-v8a` APK, подписанного постоянным сертификатом Moru;
  - проверка release-APK.

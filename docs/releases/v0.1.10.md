## Вход в OpenRouter через официальный OAuth PKCE

Добавлен второй, независимый способ подключения OpenRouter — official OAuth login, наравне с существующим ручным подключением по API-ключу (оба варианта доступны одновременно, ручной не тронут).

- Авторизация проходит по документированному потоку OpenRouter (`openrouter.ai/auth` → `POST /api/v1/auth/keys`, PKCE S256). У OpenRouter нет `client_id` и не задокументирован параметр `state` в ответе — приложение не полагается на его возврат сервером и использует собственную привязку сессии: одноразовый случайный nonce в пути callback-адреса, точное совпадение адреса, отклонение повторной или чужой доставки, закрытие слушателя при отмене входа.
- У обменянного ключа OpenRouter нет refresh-токена и срока действия — это отражено честно (учётные данные это допускают), а не подделано фиктивным значением; при 401 приложение сразу просит повторный вход, не пытаясь обновить несуществующий токен.
- После входа список доступных чат-моделей аккаунта подгружается автоматически (`/models/user?output_modalities=text`) и фильтруется до настоящих текстовых чат-моделей — из каталога исключены собственное семейство решающих моделей OpenRouter «Jev» и любые модели embeddings/rerank/image/video/audio.

## Известные ограничения

- Реализация разработана test-first (24 модульных теста с мок-HTTP: полный вход, ручная вставка кода, отклонение подмены/повтора callback, реальная проверка закрытия сокета при отмене, фильтрация моделей, разбор usage, редактирование секретов в исключениях). Настоящий вход в реальный аккаунт OpenRouter на устройстве этим релизом не проверялся — это ручной smoke-тест для пользователя после установки.

## Проверки и APK

Перед публикацией workflow выполняет полный Dart analyze, Flutter tests, Android JVM tests, проверку arm64 ABI, release-подписи и package metadata.

Один **arm64-v8a release APK**, версия **0.1.10**, versionCode **11**, пакет `com.mishaqp.moru`. Используется постоянный сертификат Moru; релиз предназначен для установки поверх предыдущего подписанного Moru без удаления данных.

# Moru v0.1.21 — статистика ответа одной строкой

## Изменения

- Всплывающее окошко «Токенов: …» под ответом убрано. Вместо него под кнопками ответа всегда видна компактная строка: `↑` входящие токены, `⛁` из них взято из кэша, `↓` токены ответа, `⚡` скорость генерации и `⏱` время ответа. Большие числа сокращаются (18.4k, 1.3M). Если провайдер сообщает только общее число токенов, показывается оно.
- Для экранного диктора строка по-прежнему озвучивает полные значения.
- Строка появляется, когда ответ готов, и скрывается вместе с остальной статистикой переключателем «Показывать статистику токенов» в настройках отображения.

## Проверка

- Новые тесты: сокращение чисел, отображение всех значений без всплывающего окна, озвучивание полных чисел, запасной вариант с общим числом токенов.
- CI: анализ, Flutter-тесты, локализация, Android JVM-тесты и сборка одного `arm64-v8a` APK, подписанного постоянным сертификатом Moru.

Версия **0.1.21** (`versionCode 22`), пакет `com.mishaqp.moru`.

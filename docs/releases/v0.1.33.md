# Moru v0.1.33 — каталог моделей models.dev и стоимость в статистике

## Изменения

- **Каталог моделей models.dev.** Приложение раз в сутки скачивает открытый каталог [models.dev](https://models.dev) и хранит его сжатую копию, около 200 КБ и 2300 моделей, в кэше.
  - Без интернета используется последняя сохранённая копия. Если скачать не удалось, прежняя копия остаётся.
  - Из каталога берутся контекстное окно, лимит ответа, цены за миллион токенов, а также поддержка инструментов и картинок.
  - Когда одну модель предлагают несколько сервисов, берутся данные самого разработчика: Anthropic, OpenAI, Google, DeepSeek и других.
- **Кольцо контекста знает почти любую модель.** Раньше окно было известно только для восьми семейств из встроенного списка. Теперь для Qwen, GLM, Kimi и других оно берётся из каталога. Например, у `deepseek-v4.1-flash` окно 1M, а не 128k, как предполагал старый список. Значение из поля «Контекстное окно» в настройках модели по-прежнему главнее. Если поле пустое, в нём подсказкой показано окно из каталога.
- **Возможности новых моделей.** Если модель не распознаётся по имени, приложение смотрит в каталог. Когда там указано, что модель вызывает инструменты или принимает картинки, это включается автоматически. «Рассуждения» из каталога не берутся: их включение меняет параметры запроса, и не каждый API их принимает. Ручные настройки модели, как и раньше, главнее.
- **Стоимость в статистике.** На странице статистики появились:
  - плитка «Примерная стоимость» в сводке;
  - секция «Расходы по моделям», где модели упорядочены по сумме.

  Расчёт идёт по ценам models.dev с учётом токенов из кэша, которые обычно дешевле. Учитываются только модели с известной ценой. Это оценка по прайсу, реальный счёт может отличаться, об этом написано под секцией.
- **План отмечается по ходу работы.** Модель просят обновлять `update_plan` сразу после каждого шага, а не в конце. В тесте 0.1.32 полоска «План 0/7» стояла, пока модель не закончила всё.

## Проверка

- Новые тесты:
  - каталог: данные разработчика важнее перепродавцов, имена моделей с префиксом, вариантом и датой находятся, стоимость с кэшем, сохранение и чтение копии, работа со старой копией после неудачной загрузки;
  - возможности: инструменты и картинки из каталога включаются, рассуждения нет;
  - статистика: суммы токенов по моделям из базы, стоимость и порядок расходов, отсутствие стоимости без цен, формат сумм.
- Анализ без замечаний, полный набор Flutter-тестов.
- CI: анализ, Flutter-тесты, локализация, Android JVM-тесты и сборка одного `arm64-v8a` APK, подписанного постоянным сертификатом Moru.

# Moru v0.1.28 — сводка правок и начало ответа в уведомлении

## Изменения

- **Сводка правок под ответом.** Если агент менял файлы, над чипами файлов появляется строка «Изменено 3 файла · +120 −40».
  - При нажатии открывается лист со всеми diff этого ответа по порядку, каждый с именем файла и своими `+/−`. Искать правки по шагам больше не нужно.
  - Учитываются только успешные правки. Ошибки и отклонённые шаги в сводку не попадают.
- **В уведомлении о готовом ответе видно его начало.** Раньше уведомление о завершении писало только «Генерация завершена» (текст показывался лишь у запланированных задач).
  - Теперь виден итоговый ответ, до 200 символов. У агентного ответа берётся последний текстовый блок, то есть вывод после всех шагов, а не «Шаг 1: читаю файл…».
  - Markdown, код и блок размышлений из текста убираются.
  - В режиме конфиденциальности текст по-прежнему скрыт.
  - Уведомления включаются в «Настройки → Фоновые задачи → Уведомления задач». По умолчанию они выключены, и включённое состояние сохраняется.

## Что проверено и оставлено как есть

- **Размытие под полем ввода.** Я сравнил попиксельно отрисовку поля ввода с размытием и без него. Без размытия сквозь поле заметно просвечивает текст ответа: в тёмной теме до 8 % яркости, в светлой до 4 %. Поэтому размытие оставлено. Во время ответа сейчас работает только одно размытие, под полем ввода. «Стеклянные» кнопки в шапке появляются только в режиме выбора сообщений.

## Проверка

- Новые тесты:
  - сводка правок: подсчёт файлов и `+/−`, открытие всех diff;
  - текст для уведомления: последний блок, без markdown и размышлений;
  - уведомление с началом ответа и режим конфиденциальности.
- Анализ без замечаний, полный набор Flutter-тестов.
- CI: анализ, Flutter-тесты, локализация, Android JVM-тесты и сборка одного `arm64-v8a` APK, подписанного постоянным сертификатом Moru.

## Shared Browser и Full Trust

Этот релиз фиксирует объединённую базовую версию Moru, от которой дальше будут делаться браузерные исправления.

- Добавлен встроенный Android Shared Browser для агента с действиями `open`, `observe`, `click`, `type`, `scroll`, `back`, `forward`, `reload` и `close`.
- Добавлен режим полного доверия инструментам: Moru может автоматически подтверждать внутренние действия инструментов без постоянных approval-запросов. Системные разрешения Android не обходятся.
- `observe` поддерживает viewport/document, ограничения текста и элементов, а также режим без агрегированного текста.
- Ввод поддерживает обычные поля, textarea, contenteditable и select; значения password не возвращаются в observe.

## Browser Research Core

В кодовую базу включено ядро следующего этапа браузерного исследования:

- BM25/query-focused extraction для длинных страниц;
- WebSource и кэш источников;
- browser research envelopes/sanitization;
- browser diff для дельт после действий.

Это ядро включено в релиз как база разработки, но `read`, `extract`, `source_id` и browser diff пока не подключены к публичному runtime-контракту `browser_use`.

## Известные ограничения базовой версии

Релиз намеренно фиксирует текущую проверенную базу перед следующим циклом исправлений. Runtime-аудит на реальном Android подтвердил:

- Full Trust работает и исходная потеря browser session после approval не воспроизводится;
- обычные open/observe/click/type/scroll работают;
- back/forward требуют доработки синхронизации и истории;
- после навигации возможен краткий устаревший/пустой observe;
- type для file input может ошибочно возвращать `browser_not_open`;
- close и lifecycle общей WebView-сессии требуют доработки;
- element IDs пока привязаны к конкретному observe и могут перенумеровываться.

Эти пункты будут исправляться уже поверх v0.1.6, чтобы релиз был стабильной контрольной точкой.

## Проверки и APK

Перед публикацией workflow выполняет полный Dart analyze, Flutter tests, Android JVM tests, проверку arm64 ABI, release-подписи и package metadata.

Один **arm64-v8a release APK**, версия **0.1.6**, versionCode **7**, пакет `com.mishaqp.moru`. Используется постоянный сертификат Moru; релиз предназначен для установки поверх предыдущего подписанного Moru без удаления данных.

# Moru v0.1.34 — мини-приложения

## Изменения

- **Мини-приложения.** Агент собирает в рабочей папке маленькое веб-приложение, а Moru открывает его как отдельное приложение: трекер воды, список покупок, карточки для слов, журнал тренировок.
  1. В чате с рабочей папкой попросите, например: «Сделай приложение — трекер воды, цель 2 литра, кнопки +250 и +500 мл».
  2. Агент пишет файлы (`index.html`, `app.js`, `icon.svg`, `moru-app.json`) и публикует их новым инструментом `publish_mini_app`.
  3. В ответе появляется ссылка «Открыть …». Нажатие открывает приложение на весь экран.
  4. Чтобы что-то поменять, попросите в том же чате («сделай кнопки крупнее»). Агент опубликует новую версию, и данные приложения при этом сохранятся.
- **Данные приложения.** У каждого приложения своё хранилище `window.moru.storage` (`get`, `set`, `remove`, `keys`, значения в JSON). Хранилище лежит отдельно от кода, поэтому обновление приложения его не стирает. Одно приложение не видит данные другого, у приложений нет доступа к чатам и ключам.
- **«Мои приложения».** Новый раздел в настройках рядом с «Задачами по расписанию», его также можно найти поиском по настройкам. Там все опубликованные приложения с иконками. Нажатие открывает приложение, долгое нажатие или «…» открывает меню: «Открыть», «На рабочий стол», «Удалить».
- **Ярлык на рабочем столе.** Кнопка с телефоном в шапке приложения или пункт меню «На рабочий стол» добавляет ярлык с иконкой приложения. Если иконки нет, рисуется первая буква названия. Ярлык открывает приложение сразу, в том числе когда Moru закрыт.
- **Как работает внутри.** Приложение открывается во встроенном WebView из отдельной копии файлов. Кнопка «Назад» сначала ходит по страницам приложения. Внешние ссылки открываются в браузере. Работают обычные теги `<script src>` и `<link>`, а `type="module"` и `fetch()` локальных файлов запрещены самим WebView для файлов. Агенту это сказано в описании инструмента.
- **Ограничения.** До 500 файлов и 20 МБ на приложение, до 5 МБ данных. Папки `node_modules`, `.git` и `__pycache__` не копируются.
- **Инструмент `publish_mini_app`** включён для рабочих папок по умолчанию. Его можно выключить в настройках инструментов рабочей папки, как остальные.

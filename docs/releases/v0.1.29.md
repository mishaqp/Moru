# Moru v0.1.29 — правки по итогам проверки 0.1.28

## Изменения

- **Лист «Изменённые файлы» группирует правки по файлу.** Раньше каждая правка шла отдельным блоком, и `calc.py` повторялся несколько раз. Теперь у каждого файла один блок: заголовок с общими `+/−` и все его правки подряд, без повторных строк `---`/`+++`. Число в заголовке листа — количество файлов.
- **Без двойного слеша в diff.** Заголовки вида `--- a//workspace/…` теперь пишутся как `--- a/workspace/…`.
- **Под ответом больше нет кэша Python.** После `python3 -m unittest` в чипах файлов появлялись `*.cpython-312.pyc`. Папки `__pycache__` и `node_modules` теперь не просматриваются при поиске файлов, изменённых командой. Поэтому они не попадают под ответ, а после `npm install` проверка изменённых файлов проходит заметно быстрее.
- **Настройки → Отображение → Отображение сообщений.** Проверил все 13 переключателей, каждый работает. Поправил иконки:
  - «Показывать имя пользователя» — карточка вместо облачка сообщения;
  - «Аватар ассистента в заголовке чата» — панель заголовка вместо второго робота (робот остаётся у «Значок модели в чате»);
  - «Показывать название модели» — ярлык;
  - «Статистика токенов и контекста» — спидометр вместо буквы «T».
  - Подсказка «Показывать файлы под ответами» теперь говорит и о сводке правок: переключатель управляет ею тоже.
- **PRoot 5.1.107.95.** Termux убрал из своего репозитория сборку 5.1.107.94, из-за чего любая сборка APK падала ещё при скачивании. Версия и контрольные суммы `libproot_exec.so` и `libproot_loader.so` обновлены. `libtalloc` и `libandroid-shmem` не изменились. Это патч-выпуск того же PRoot 5.1.107. После установки стоит проверить терминал рабочей области.

## Проверка

- Новые тесты:
  - склейка правок одного файла, в том числе удалённая строка, начинающаяся с `--`, не теряется;
  - обход пропускает `__pycache__` и `node_modules`;
  - заголовок diff для абсолютного пути.
- Анализ без замечаний, полный набор Flutter-тестов.
- CI: анализ, Flutter-тесты, локализация, Android JVM-тесты и сборка одного `arm64-v8a` APK, подписанного постоянным сертификатом Moru.

# Moru v0.1.14 — локальные модели LiteRT-LM

## Что нового

- Встроенный центр локальных моделей: каталог, сведения о размере и возможностях модели, импорт собственного файла `.litertlm`, список установленных моделей и их удаление.
- Для доступных моделей из каталога: загрузка с отображением прогресса, отмена и продолжение по HTTP Range. Перед установкой проверяются размер, формат и SHA-256 файла. Для моделей с ограниченным доступом показана страница модели и путь ручного импорта; скачивание в приложении для них недоступно.
- Настройки установленной модели: CPU/GPU, размер контекста, температура, Top K/Top P, бюджет рассуждения, аудиоввод и удержание модели в памяти. При сохранении сохраняются путь к файлу и метаданные установленной модели.
- Локальная генерация через LiteRT-LM 0.17.1, потоковый ответ и отмена. Подключены поддерживаемые моделью изображения, аудио, рассуждение и вызовы инструментов с уже существующим механизмом разрешений Moru.
- Стабильная идентификация модели при повторном импорте и восстановление ссылок на модели из ранних тестовых сборок.

## Ограничения и проверка

- Работа вывода с конкретной моделью, GPU, камерой/аудио и инструментами на физическом Android-устройстве этим выпуском ещё не подтверждена. Возможности зависят от самой модели и телефона; при проблеме с GPU переключитесь на CPU.
- Релизный workflow запускает полный анализ и тесты, Android JVM тесты, собирает один APK только для `arm64-v8a` и проверяет его пакет, версию, SHA-256 и постоянный сертификат подписи.

Версия **0.1.14** (`versionCode 15`), пакет `com.mishaqp.moru`.

# Moru v0.1.32 — задачи по расписанию из чата, полный календарь и кольцо контекста

## Изменения

- **Задачи по расписанию из чата.** Новый локальный инструмент «Задачи по расписанию» (`manage_scheduled_tasks`) позволяет модели:
  - показывать список задач со временем следующего запуска;
  - создавать задачи: название, текст запроса, время, повтор (один раз, каждый день, по будням или в выбранные дни), даты начала и конца;
  - менять и удалять задачи.

  Задача может запускаться в новом чате или продолжать текущий («напомни мне здесь завтра в 18:00»). По умолчанию её выполняет ассистент, с которым идёт разговор. Создание, изменение и удаление требуют вашего подтверждения, просмотр списка — нет. Это те же задачи, что в разделе «Задачи по расписанию»: всё созданное из чата видно и редактируется там. Инструмент включается в настройках ассистента на вкладке «Локальные инструменты».
- **Календарь целиком.**
  - Новые инструменты «Изменить событие» (`calendar_update`) и «Удалить событие» (`calendar_delete`). Можно менять время, название, место, описание и напоминания. При переносе начала без указания конца длительность события сохраняется. У повторяющегося события здесь меняются только название, описание, место и напоминания. Удаление повторяющегося события убирает всю серию, и модель об этом предупреждена. Оба действия требуют подтверждения.
  - «Чтение календаря» теперь возвращает `calendar_id` у каждого события. По запросу он также выдаёт список календарей устройства с отметкой, в какие можно записывать. Выборку можно ограничить одним календарём.
  - «Создать событие» может записать событие в выбранный календарь, а не только в основной.
- **Кольцо заполнения контекста** слева от кнопки «+» в поле ввода. Оно показывает, какая часть контекстного окна модели уже занята. По нажатию видны числа, например «Контекст: 45.2k из 200k токенов (23%)».
  - Занятый объём берётся из последнего ответа: входные токены плюс ответ. После «Очистить контекст» кольцо пустеет.
  - Цвет меняется от 85 % заполнения, а при переполнении кольцо становится красным.
  - Кольцо включается тем же переключателем, что и статистика токенов: «Настройки → Отображение → Статистика токенов и контекста».
- **Контекстное окно модели** можно указать в её настройках, в новом поле «Контекстное окно (токены)». Если поле пустое, для известных семейств (Claude, Gemini, GPT-4o/4.1/5, o1/o3/o4, DeepSeek, Grok 4) берётся стандартное значение, оно показано подсказкой в поле. Для остальных моделей кольцо показывает только число токенов и подсказывает, где задать окно.

## Проверка

- Новые тесты:
  - инструмент задач: создание, продолжение текущего чата, частичное изменение без потери остальных настроек, удаление, ошибки (время, дата, дни недели, прошедшая дата, неизвестный ассистент или задача), отказ нативной стороны, список;
  - календарь: изменение и удаление вызывают нужные нативные методы и требуют подтверждения;
  - контекст: окна известных семейств, токены из последнего ответа, подсказка кольца, кольцо в поле ввода и его отключение.
- Анализ без замечаний, полный набор Flutter-тестов.
- CI: анализ, Flutter-тесты, локализация, Android JVM-тесты и сборка одного `arm64-v8a` APK, подписанного постоянным сертификатом Moru.

Версия **0.1.32** (`versionCode 33`), пакет `com.mishaqp.moru`.
